# E-commerce Customer Retention Analysis

## Project Overview
This project analyzes e-commerce customer retention using machine learning techniques including Exploratory Data Analysis (EDA), K-Nearest Neighbors (KNN) classification, and K-Means clustering.

## Dataset
- **Size**: 100 customers
- **Features**: 9 columns including CustomerID, Age, Gender, MembershipType, PurchasesLastMonth, AvgPurchaseValue, IsRetained, Region, ShoppingAlone

## Key Results
- **KNN Classification Accuracy**: 75%
- **Customer Segments**: 3 distinct clusters identified
- **Retention Rate**: 20%
